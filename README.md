# Online Clothing Store Management System

A Python Flask-based web application for managing an online clothing store.

## Features
- User authentication
- Product management
- Shopping cart
- Admin panel

## Technologies Used
- Python
- Flask
- HTML, CSS, Bootstrap
- SQLite
